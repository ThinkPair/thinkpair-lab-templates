# 自媒体运营看板第一版｜使用说明

> [!warning] 2026-08-07 已降级
> 该Web原型未形成收费或持续真实使用，现作为历史按需资产保留；账号运营能力继续通过真实内容生产与数据回填积累。见[[70_Governance/未变现项目降级与根库瘦身清单-2026-08-07]]。

## 当前成品

这是可运行的桌面端高保真原型，不是静态效果图。

- 首页：内容触达 → 新增关注 → 有效线索 → 深度沟通 → 首次付费 → 升级续费的六级经营链路 + 有效线索来源环图 + 近 4/12 周累计趋势 + 数据证据。
- 可交互：平台筛选、时间范围、漏斗阶段明细抽屉、补录数据流程、内容归因页、历史回测页、数据明细页。
- 数据口径：触达为事件量；关注、线索和沟通为平台记录；付费与续费为订单；跨平台身份未去重。
- 首页经营数据仍为演示数据；“内容归因 → 历史回测”已接入第 01—03 期抖音近似同窗口的真实平台证据，未知字段保持为空。
- 1440 × 1024 目标图同屏 QA、桌面/手机复核、核心交互、生产构建与打包回归均已通过。

## 三期历史回测

从顶部进入“内容归因”，再切换到“历史回测”。

- 第 01—03 期均为发布后回填的盲化评分，用于初始化评分规则，不计入预测命中率。
- 三期比较窗口约为发布后 19—24 小时；页面同时展示稿件评分与有证据的发布实绩。
- 第 03 期依据当前制作文字评分，尚无独立锁稿证据，页面已单独提示。
- 第 04 期才是第一条真正的发布前盲测：终稿出现后，先冻结终稿哈希、预测区间、rubric 版本和评分时间，再发布并按同窗口回填。
- 本模块不输出“爆款概率”，也不根据三条样本直接判断选题或脚本成败。

## 本地打开

双击 `打开自媒体运营看板.cmd`。脚本会在本机启动预览并打开 `http://localhost:4173/`。

若首次打开还没有安装依赖，脚本会先执行本地依赖安装。
