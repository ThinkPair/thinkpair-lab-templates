# DB 咖啡店运营知识库 v0.1 样板

> [!warning] 2026-08-07 已降级
> 这是历史样板，不是用户真实经营资产，也不进入当前产品推进。

这是一套给小咖啡店老板 / 店长使用的轻量经营知识库样板。

第一版只做三件事：

1. **后台**：把物料成本和产品毛利算清楚。
2. **销量记录**：每天记录各产品销量，看出爆品和滞销品。
3. **会员整理**：整理老客、口味偏好、储值权益和回访线索。

它不是大 ERP，也不是收银系统替代品。它更像一个每天 10 分钟能打开的经营驾驶舱。

## v0.1 使用口径

先跑 7 天，不追求完美。

每天闭店前先把销量填上；有空再补成本和会员。只要一周后能回答“什么产品赚钱、什么产品真卖、哪些老客值得维护”，这套系统就已经开始发挥作用。
