# 像素经营沙盘素材库 v0.1

## 本轮范围

本库最初只服务已完成的虚构咖啡店与“客户为什么越来越少”诊断链。Batch 02／03 曾按经营母型继续生产奶茶、花店、健身和预约美容的店内设备与状态；用户随后发现产品实际只展示门脸，店内设备既用不上也容易用错，因此这部分现只保留为历史生产记录。

M1 风格素材与 M2 一店五状态已经通过用户目检，作为不可推翻的视觉基准。v0.3 四张时间系统样张只作为构图与时间氛围参考；按用户 2026-08-05 本轮最新口径，其最终接入验收尚未完成，不能登记为已锁定上线。

## 当前素材范围｜门脸优先

2026-08-05 用户最新纠偏后，新增生产只允许三类：

1. NPC、顾客、店员及其动作；
2. 不同行业、店型和场地的正面门脸；
3. 同一门脸从外部可见的动态，例如施工／落成、门开／门关、灯亮／灯灭、正常／新开／闭店竞品、稀疏／正常／拥挤客流和进店／离店。

## 后续行业与店型扩展

素材库未来不只包含咖啡店，但行业扩展只改变门脸建筑、外部开口、招牌留白和 NPC，不再为 A–F 经营母型逐项生产内部设备。

商场沿边店、商场岛柜、楼上／大型场馆、预约工作室和项目工作室均已纳入候选店型。完整映射与建议生产顺序见 [经营母型与店型素材扩展路线图-v0.1-2026-08-05.md](经营母型与店型素材扩展路线图-v0.1-2026-08-05.md)。

该路线图最初按“门脸＋行业设备”规划，Batch 02／03 已执行部分内容；最新门脸范围纠偏已覆盖其中的内部对象生产建议。它们仍可作为历史业务语义映射，但不再是当前生产队列。

核心生产规则仍是“拼装优先”，但拼装层收窄为环境底板、门脸壳、门脸外部动态、NPC和客流。只有真正缺失的新门脸轮廓、人物动作或门脸可见状态才调用 ImageGen；内部行业对象一律不再生成。
