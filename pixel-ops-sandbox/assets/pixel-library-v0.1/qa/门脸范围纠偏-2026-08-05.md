# 像素素材门脸范围纠偏｜2026-08-05

## 结论

此前把“经营变量”直接画成咖啡机、健身器材、美容工位、花材库存等店内对象，属于产品展示层级错误。当前产品只展示门脸，因此素材主线从“店内经营对象库”收窄为：

1. NPC、顾客与店员人物；
2. 不同行业、店型和场地的正面门脸；
3. 同一门脸从外部可见的经营动态。

本次是 scope 纠偏，不是删除资产，也不是否定图片本身的视觉 QA。已有内部设备文件保留为历史生产记录或可拆源图，但不继续扩图、不进入当前网站、直播和短视频核心素材调用。

## 当前允许生产

### NPC

- 诊断负责人、经营者、店员和顾客；
- 走路、进店、离店、驻足、咨询、记录、指向、思考等人物动作；
- 稀疏、正常、拥挤与门外排队等外部客流组合。

### 门脸

- 临街店、商场沿边店、商场岛柜／开放店面、楼上大型店、预约工作室等不同外观；
- 咖啡、花店、健身、预约服务等行业只通过建筑比例、开口、橱窗、招牌留白、入口和外部陈列形成差异；
- 不通过机器、器械、货架或工位来证明行业。

### 门脸动态

- 空地 → 施工／围挡 → 落成；
- 门开／门关、灯亮／灯灭、营业／闭店；
- 正常竞品／新开竞品／闭店竞品；
- 客流稀疏／正常／拥挤、进店／离店、门外排队；
- 在保持同一建筑几何前提下，可从外部清楚看到的维护良好／冷清／活跃等变化。

数值、店名、库存、利润、诊断结论、路线、经营半径、已确认／待核实状态继续由 HTML/SVG/CSS 实现。

## 当前禁止生产

- 咖啡机、磨豆机、封口机、收银台、取餐架；
- 跑步机、力量器械、闸机、鞋包柜；
- 美容椅、镜台、工位、工具车；
- 花材库存、花桶数量、货架、库龄、积压对象；
- 店内座位占用、设备利用率和内部排队；
- 任何依赖店内设备才能理解的完整拼装场景。

## 新的验收门

每个新资产必须先回答：

1. 它是否能在门脸视角直接看到？
2. 不看文字时，它是人物、门脸还是门脸动态中的哪一种？
3. 它是否复用了同一建筑几何，而不是为状态变化重画整店？
4. 它是否需要店内机器／器械才能被理解？若需要，停止生产。
5. 它是否会被网站、直播或短视频的门脸镜头直接调用？若不会，不生产。
