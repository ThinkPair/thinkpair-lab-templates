# 像素经营沙盘｜经营母型与店型素材扩展路线图 v0.1

## 这份路线图解决什么

当前 Batch 01 只是“临街咖啡店＋客户为什么越来越少”诊断链的第一批组件，不代表素材库最终只有咖啡店。

未来扩展沿用知识库已经确认的六种经营母型，不重新按热门行业拍脑袋分类。但经营母型只决定诊断信息，不再逐项转译成店内位图。当前把三个层级分开：

1. 经营母型：决定要显影什么经营变化；
2. 店型／场地：决定门脸建筑壳、客流入口和外部关系；
3. NPC／门脸动态：决定人物动作与从外部可见的经营变化。

本页先建立未来素材分类与生产顺序。用户随后明确授权启动 Batch 02，因此奶茶、花店、健身和预约美容只各生产了用于验证拼装复用的代表模块与样景；这不修改当前诊断逻辑，也不代表六套行业产品同时进入制作。

### 2026-08-05 当前覆盖规则｜门脸优先

用户最新确认产品画面只展示门脸。内部咖啡机、封口机、花材库存、货架、健身器材、美容工位、座位和设备利用率全部退出当前生产队列。后续只生产 NPC、不同门脸，以及同一门脸的外部可见动态。本页下方保留的内部对象文字只作历史业务语义，不再授权 ImageGen。

## 已确认的六种经营母型

| 代号 | 经营母型 | 首先显影的问题 | 知识库中的典型业务 | 对应像素状态重点 |
|---|---|---|---|---|
| A | 获客转化型 | 来问的人在哪一步没有继续付款 | 内容／知识付费、招商、咨询获客、课程销售、复杂销售 | 路过、驻足、咨询、留资、体验、报价、付款、流失 |
| B | 高频交易与单位经济型 | 订单够不够，每单是否真正留下钱 | 咖啡、餐饮、便利零售、高频小额门店 | 稀疏／正常／拥挤客流，点单、制作、取餐、座位、外卖 |
| C | 库存周转与资金占用型 | 钱压在哪些货里，哪些该补、该清或正在缺货 | 服装、运动用品、多 SKU 零售、经销、季节性备货 | 缺货、正常库存、积压、库龄、清货、货架空满 |
| D | 会员生命周期型 | 会员是否使用、留存，预收义务是否健康 | 美业、健身、教培、洗车、养生、会员制门店 | 新会员、活跃、沉睡、临期、核销、续费、退款 |
| E | 产能预约与资源利用型 | 人、房间、座位、工位或设备是否被有效使用 | 美容美发、诊所、维修、摄影、酒店、月子中心、球馆 | 空闲、正常使用、满载、预约、取消、爽约、等待 |
| F | 项目交付与回款型 | 项目做到哪一步，交付的钱何时回来 | 咨询、代运营、工程、定制生产、B2B 服务 | 咨询、报价、在制、交付、待验收、待回款 |

沿用已确认的组合规则：一个主母型＋最多一个副母型。行业名称只决定先看哪里，不能代替真实经营行为。

## “创业四大坑”放回经营母型

这里不把“四大坑”当产品真理，只把它作为用户容易理解的首批行业入口。

| 行业 | 建议主母型 | 建议副母型 | 当前门脸区分要点 |
|---|---|---|---|
| 咖啡店 | B 高频交易 | C 库存周转 | 紧凑正立面、通透双窗、温和遮阳篷、留白招牌和门前进出顾客；不画咖啡机 |
| 奶茶店 | B 高频交易 | C 库存周转 | 更明显的外带开口、明亮檐口、门外取餐／排队 NPC；不画封口机和取餐架 |
| 花店 | C 库存周转 | B 高频交易；若定制业务更重要则改为 F | 大橱窗、较轻盈的门框、外部少量植物／花束陈列和花艺师 NPC；不画库存量 |
| 健身房 | D1 储值／课包 | E 产能预约 | 更宽入口、大面积蓝灰玻璃、楼上／大型场馆到达感和会员 NPC；不画器械 |

## 四大坑之外需要补充的行业入口

不是每个行业都立即做整套素材。每个母型先选择一至两个差异明显的代表行业，验证建筑与经营状态能否复用。

| 经营母型 | 首批代表行业 | 后续可复用行业 | 当前应画的门脸／NPC对象 |
|---|---|---|---|
| A 获客转化 | 咨询／体验工作室、课程招生点 | 招商、知识服务、复杂销售 | 工作室门脸、接待／咨询／离开 NPC、门前驻足变化 |
| B 高频交易 | 咖啡、奶茶、小餐饮 | 烘焙、便利店、水果店、快餐 | 高频小店门脸、进店／离店／门外排队和外卖员 NPC |
| C 库存周转 | 花店、茶叶店 | 服装、运动用品、礼品、母婴零售 | 零售门脸、橱窗外观、送货／清货 NPC；库存数值由 HTML 表达 |
| D 会员生命周期 | 健身房、美业 | 教培、洗车、养生、年费门店 | 会员型门脸、重复到店／离店 NPC、门外活跃度变化 |
| E 产能预约 | 美容美发、维修店 | 诊所、摄影、酒店、球馆、宠物服务 | 预约工作室门脸、到店／等待／爽约离开 NPC；不画工位利用率 |
| F 项目交付 | 定制工作室、咨询／代运营办公室 | 工程、企业服务、定制生产 | 项目工作室门脸、客户到访／交付 NPC；项目阶段由 HTML 表达 |

## 店型与场地层

商场店必须纳入，但商场不是一种行业，而是一种场地结构。它会改变流量来源、入口、排队和空间约束，不能只把临街店换一张背景。

| 店型代码 | 场地母版 | 适配行业 | 需要显影的空间变量 |
|---|---|---|---|
| S1 | 临街完整正立面店 | 咖啡、花店、奶茶、便利零售、美业 | 经过客流、驻足、进店、门前排队、竞品距离 |
| S2 | 临街外带窗口／小档口 | 奶茶、咖啡、烘焙、快餐 | 窗口可见性、门外取餐／外卖聚集和外部排队 |
| M1 | 商场沿边店／内铺 | 咖啡、花店、奶茶、美业、服装 | 楼层动线、扶梯方向、店面开口、邻店分流 |
| M2 | 商场岛柜／中岛 | 花店、奶茶、咖啡、礼品 | 四向可见性、外部排队外溢、开放边界和无独立门体 |
| L1 | 楼上店／大型场馆 | 健身、教培、摄影、球馆 | 电梯／楼梯到达、入口宽度、门脸可见性和门外等候 |
| R1 | 预约工作室／服务门店 | 美容、维修、诊所、宠物服务 | 入口私密度、预约到店、门外等待和爽约离开 NPC |
| P1 | 办公室／项目工作室／小型工坊 | 咨询、代运营、定制、B2B 服务 | 客户到访、门口交付、营业状态和项目阶段信息覆盖 |

不是每个行业都做七种店型。只选择现实中决定经营机制的主场地，避免形成“行业数量 × 店型数量 × 状态数量”的失控乘法。

## 素材复用结构

### 拼装优先原则

本素材库采用“像素积木”生产方式。新的行业、店型或经营状态，默认先通过已有透明部件拼装，不直接重新生成整张门店。

固定判断顺序：

1. 现有门脸或店型壳能否直接复用；
2. 能否只替换门、窗灯、卷帘、遮阳篷、外部维护状态或招牌留白；
3. 能否通过 NPC、客流和门外排队叠加完成；
4. 能否用 SVG／CSS／HTML 完成路线、标签、数值和证据状态；
5. 只有缺少新的门脸轮廓、人物动作或门脸可见动态时，才单独调用 ImageGen；店内对象直接停止。

#### 固定拼装层

| 层级 | 内容 | 默认来源 |
|---|---|---|
| L0 环境底板 | 街道、商场走廊、楼层入口、基础光线 | 少量固定底板 |
| L1 门脸／店型壳 | 临街店框架、商场沿边店、岛柜、楼上大型场馆、预约工作室 | 可复用门脸母壳 |
| L2 门脸识别层 | 门窗、遮阳篷、招牌留白、外部少量陈列与行业可见外观 | 透明 PNG／WebP 部件 |
| L3 门脸动态 | 施工／落成、门开／关、灯亮／灭、卷帘、正常／新开／闭店 | 同几何局部替换层 |
| L4 NPC 与客流 | 顾客、店员、经营者、队列、咨询与离店动作 | 共用人物库 |
| L5 信息覆盖 | 店名、数值、路线、经营半径、证据标记和状态标签 | SVG／CSS／HTML |

#### 允许的复用操作

- 平移、遮挡、裁切和层级组合；
- 保持整数倍像素密度的缩放；
- 在不改变动作含义时水平翻转；
- 在固定低饱和色盘内制作次要人物配色版本；
- 用局部部件替换门、窗灯、卷帘、遮阳篷和外部维护状态。

#### 禁止的伪复用

- 把“进店”直接翻转冒充“离店”，却不检查身体朝向和手持物；
- 任意拉伸人物或建筑；
- 为了换行业只改招牌，而门脸建筑比例、开口和外部入口仍完全相同；
- 为了换状态重新生成整家店，导致建筑比例、门窗和像素密度漂移；
- 用咖啡机、健身器材、库存或工位等店内对象解释门脸状态；
- 把文字、数字、路线或诊断结论烘焙进位图。

### 全行业共用

- 成年顾客、经营者、店员和外部人员；
- 稀疏、正常、拥挤客流；
- 进店、驻足、咨询、离店、等待、排队；
- 经营半径、路线、标签、数值和证据标记继续使用 SVG／CSS／HTML。

### 店型共用

- 临街道路、门体、橱窗、外摆；
- 商场走廊、扶梯口、沿边店开口、岛柜边界；
- 楼上店入口、电梯／楼梯到达方向和门外等候；
- 工作室入口、私密橱窗、预约到店与客户交付人物。

### 历史内部业务语义｜当前冻结

下列对象仍可帮助理解行业经营，但不再是门脸素材生产项：

- 咖啡／奶茶的制作与取餐设备；
- 花店的花材、花桶、冷柜和包装台；
- 健身房的器械、教练和会员使用状态；
- 零售行业的货架、库存和库龄状态；
- 预约行业的房间、工位与设备状态；
- 项目行业的样品、在制品、交付物和验收状态。
