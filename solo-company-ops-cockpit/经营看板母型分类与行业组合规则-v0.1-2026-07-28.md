# 经营看板母型分类与行业组合规则 v0.1｜2026-07-28

> [!success] 用户已确认
> 2026-07-28，用户确认六种经营母型及“一个主母型＋最多一个副母型”的行业组合规则可以作为v0.1产品分类。确认只锁定分类方法，不代表六套模板同时进入制作。

## 核心纠偏

用户提出的方向成立，但当前四类混合了两个层级：

- 漏斗、库存、储值描述的是**生意怎样运转**；
- 线型图、数字卡、饼图描述的是**数据怎样显示**。

因此不能按图表类型划分行业。正确结构是：

```text
经营母型：决定首页首先回答什么问题
        ↓
图表语法：决定用漏斗、折线、结构图、账龄或热力图怎样表达
        ↓
行业模板：把母型翻译成该行业的对象、字段、口径和语言
```

## 六种经营母型

### A. 获客转化型

**核心问题：人在哪一层流失，哪个来源带来的客户质量最高？**

典型业务：

- 内容账号、知识付费、社群；
- 咨询获客、招商加盟；
- 课程销售、复杂销售；
- 需要从大量曝光逐层转成付费的业务。

主要经营对象：

- 曝光／播放事件；
- 有效观看／主页访问；
- 关注、私信、留资、进群；
- 首次付费；
- 使用、续费或升级。

主图表语法：

- 当前周期漏斗；
- 各层转化率趋势；
- 来源质量对比；
- 同批用户的后续转化。

重要边界：

- 播放量是事件数，关注或进群通常是人数，不能在没有归因和去重时伪装成精确人员漏斗。
- 静态漏斗只能看截面，必须同时保留各层趋势，否则看不出哪一层正在恶化。

### B. 高频交易与单位经济型

**核心问题：今天／本周卖了多少，每一单是否真正贡献利润？**

典型业务：

- 咖啡、餐饮、便利零售；
- 高频小额门店；
- 订单连续发生、经营结果随时间波动的业务。

主要经营对象：

- 营业额、订单、客单；
- 堂食／外卖／自取等渠道；
- 餐段、星期、天气和活动；
- SKU／品类结构；
- 单位贡献、变动成本和月度经营利润。

主图表语法：

- KPI数字条；
- 营业额、订单或单位贡献的单指标折线；
- 渠道／餐段／品类结构图；
- 月度利润与保本对比。

重要边界：

- 日经营优先看单位贡献，不把尚未合理分摊的固定成本伪装成精确日利润。
- 多种单位不叠在同一纵轴；收入、订单、客单和利润通过切换或分图比较。

### C. 库存周转与资金占用型

**核心问题：现金压在哪些货里，哪些该补、哪些该清、哪些正在缺货？**

典型业务：

- 服装批发、运动用品；
- 多SKU零售、经销；
- 备货周期长、季节性强的业务。

主要经营对象：

- 期初、采购、销售、期末库存；
- 库存成本金额；
- 售罄率、周转天数、库龄；
- 缺货、滞销、退换；
- SKU／颜色／尺码／仓库。

主图表语法：

- 库存金额与销量的时间趋势；
- 库龄分层堆叠条；
- 销量×毛利或库存金额×库龄矩阵；
- 补货、缺货与清货清单。

重要边界：

- 库存下降不一定是好事，也可能是缺货；库存趋势必须与销量、毛利和缺货共同解释。
- 单一折线看不出哪些SKU占用现金，必须有库龄或二维矩阵。

### D. 会员生命周期型

**核心问题：会员是否持续使用和留存；预收义务或下一期续费是否健康？**

本母型必须分成两个不能混算的子型：

- **D1 储值／次卡／课包**：先收钱后履约，重点是未履约负债、核销、退款和临期；
- **D2 订阅／年费会员**：按周期持续付费，重点是活跃、续费、流失和经常性收入。

典型业务：

- 美业、健身、教培；
- 洗车、养生、会员制门店；
- 次卡、储值卡、课包和预付套餐。
- 知识星球、会员社群和其他年费／订阅产品。

主要经营对象：

- D1的新增储值现金、已消费／已核销金额和未履约余额；
- D2的新增订阅、活跃订阅、续费、流失和经常性收入；
- 活跃、沉睡、临期会员；
- 复购、续费、退款和过期风险。

主图表语法：

- D1的收款现金、确认收入、未履约余额及账龄；
- D2的新增、活跃、续费与流失趋势；
- 会员活跃与续费队列；
- 入会批次留存／消费曲线。

重要边界：

- 储值到账不是当期营业收入；现金、确认收入和履约负债必须分开。
- 订阅年费不能套用储值核销口径；D1与D2必须先选型再计算。
- 会员数量不能代替会员质量，必须看活跃、消费、留存和未履约义务。

### E. 产能预约与资源利用型

**核心问题：有限的人、房间、设备或时间是否被有效使用？**

典型业务：

- 美容美发、诊所、维修、摄影；
- 酒店、月子中心、球馆；
- 强预约、强排班或固定床位／房态业务。

主要经营对象：

- 可用工时／房晚／设备时段；
- 预约、到店、取消和爽约；
- 利用率、空档和超负荷；
- 员工／房间／设备产出；
- 服务时长和等待时间。

主图表语法：

- 日历或排期热力图；
- 预约→到店→完成小漏斗；
- 产能利用率趋势；
- 人员／房间／设备效率对比。

重要边界：

- 高利用率不一定健康，过载可能降低体验和复购。
- 产能必须以真实可用时间为分母，不能使用理论最大值制造虚假低效。

### F. 项目交付与回款型

**核心问题：机会走到哪一步，交付是否按期，钱何时真正到账？**

典型业务：

- 一人公司、自由职业、咨询和代运营；
- 工程、定制生产、B2B服务；
- 按项目签约、分阶段交付与收款的业务。

主要经营对象：

- 机会、报价、合同；
- 里程碑、交付、验收；
- 应收、实收、账龄；
- 负责人、产能和风险。

主图表语法：

- 商机／订单管道；
- 项目时间线或里程碑；
- 回款趋势和应收账龄；
- 项目贡献与产能占用。

重要边界：

- 报价不等于应收，签约不等于到账，到账不等于已确认收入。
- 原“一人公司六字段”适合做本母型的轻量行业模板，不适合作为所有实体行业的通用内核。

## 图表语法不是经营母型

所有母型都可能使用折线、数字卡和结构图，但承担的任务不同：

| 图表语法 | 回答的问题 | 不适合单独承担 |
|---|---|---|
| 数字指标 | 当前结果是多少 | 为什么变化、由什么组成 |
| 折线／面积 | 随时间怎样变化 | 库龄、漏斗、会员批次 |
| 漏斗 | 各环节数量和转化 | 跨周期趋势、履约负债 |
| 饼／环／堆叠条 | 当前结构由什么组成 | 类别过多、时间变化 |
| 账龄分层 | 货、应收或储值压了多久 | 实时交易趋势 |
| 矩阵／热力图 | 哪些对象落在高价值或高风险区 | 精确过程顺序 |
| 日历／排期 | 时间和产能在哪里空闲或冲突 | 利润和现金关系 |
| 队列／清单 | 下一批需要处理的对象 | 整体趋势 |

## 行业不是单选，而是“主母型＋副母型”

同一行业往往同时包含两种经营机制。首页只突出主母型，副母型进入第二层，避免重新做成万能大屏。

| 行业／业务 | 主母型 | 副母型 | 首页第一问题 |
|---|---|---|---|
| 降噪实验室 | A 获客转化 | D2 订阅／年费会员 | 内容流量有没有转成持续关系和付费 |
| 单店咖啡／小餐饮 | B 高频交易 | C 库存周转 | 交易量和单位贡献是否支撑这家店 |
| 服装／运动用品批发 | C 库存周转 | F 项目回款 | 现金压在哪些货和客户账期里 |
| 美业／健身 | D1 储值履约 | E 产能预约 | 预收现金背后的履约和到店是否健康 |
| 教培 | D1 储值履约 | A 获客转化／E产能 | 课包履约、续费和新招能否闭环 |
| 咨询／代运营 | F 项目回款 | A 获客转化 | 机会、交付和现金是否顺利衔接 |
| 酒店／月子中心 | E 产能利用 | A 获客转化 | 未来房态／床位能否被高质量订单填满 |

## 模板选择规则

首次建档时不先问“你想看什么图”，而问：

1. 这门生意最终靠什么结果赚钱；
2. 当前最稀缺、最容易卡住的是客户、订单、货、会员义务、产能还是回款；
3. 钱主要在哪一个环节形成、占用或变成负债；
4. 经营者每周最需要发现哪一种变化；
5. 哪一种错误判断会造成最大损失。

据此选择：

```text
一个主母型
+ 最多一个副母型
+ 行业字段和语言
= 首版行业模板
```

禁止一开始同时激活三个以上母型；若所有模块都重要，先选出对现金和生存影响最大的主约束。

## 当前建议

1. 先用降噪实验室验证A型漏斗模板，但严格区分事件量、人数和可归因转化。
2. 用咖啡／小餐饮验证B型主模板＋C型副模板。
3. 暂不单独制作D、E、F模板，只先冻结数据合同和示例字段。
4. 两个模板验证后，再判断六型是否需要合并、拆分或新增订阅留存、平台撮合等特殊母型。
