# 验证记录目录

每次能力验证独立保存，使用 `../模板_验证记录.md`。

这里可以保存待验证假设、真实回复、外部证据和 AI 建议，但四类内容必须分栏。未回复对象仍是验证对象，不是项目；外部市场数据也不能证明某个具体客户已经开始讨论工作。

通过真实项目事实门后，用户直接要求建立项目时，AI 校验六字段后直接创建项目文件；如果是 AI 主动建议转项目，则先展示一次六字段短预览。AI 不直接搬运、删除或改名验证记录。

## 从个人能力工具导入

受控能力卡导入后仍然只生成一份验证记录，并固定保持以下初始边界：

- `validation_status: planned`
- `fact_gate_confirmed: false`
- `fact_gate_confirmed_at: null`
- `价格假设`、`回应与讨论证据` 为空
- 不生成客户、项目、报价、回款或经营核算

导入记录用 `source_transfer_id + source_transfer_hash` 保留来源。个人工具中的作品与反馈只进入 `source_evidence_*`，不能写成商业端的“外部证据”，也不能证明市场需求。
