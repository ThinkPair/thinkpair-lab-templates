# ThinkPair Lab Templates

Open-source blank masters and prototypes from ThinkPair / 降噪实验室.

Each folder is a separate product. They are blank or demo-only — **no personal OS vault, no trading ledgers, no real student data, no live operator metrics**.

## Products

| Folder | Product (CN) | Notes |
|--------|--------------|-------|
| `solo-company-ops-cockpit/` | 一人公司商业运营专家驾驶舱（根产品母版） | Blank Obsidian + tooling master |
| `ability-compound-cockpit/` | 个人能力复利驾驶舱（根产品母版） | Blank master; excludes `node_modules` |
| `personal-noise-starter/` | 个人降噪启动包 | Vault template only (no Electron runtime) |
| `local-ops-dashboard-blank/` | 本地经营看板空白包 | Demo data only |
| `self-media-ops-dashboard/` | 自媒体运营看板 Web 原型 | Source without `node_modules`/`dist` |
| `microbiz-diagnosis-agent/` | 小微服务生意经营诊断 Agent | Web source without build artifacts |
| `pixel-ops-sandbox/` | 像素经营沙盘 | Assets + proofs (web eng relocated) |
| `thinkpair-whitebox-demo/` | thinkpair-whitebox-demo | Demo pages; proprietary fonts removed |
| `db-cafe-ops-kb-sample/` | DB咖啡店运营知识库样板 | Sample vault structure |
