# Personal Noise Starter（个人降噪启动包）

Blank Obsidian vault template for personal noise reduction / focus loops.

This public package contains **only the blank vault template**, not the Windows Electron/Obsidian runtime binaries from the original delivery zip.

## Use

1. Copy `vault-template/` to a folder you own.
2. Open it with Obsidian.
3. Follow `00_开始这里/`.
4. API keys (if any) stay local — templates use placeholders only.
