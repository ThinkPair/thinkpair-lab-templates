# 故障排查

## 打不开降噪实验室

先确认你是从最外层文件夹双击：

`1_打开降噪实验室.exe`

如果系统拦截，请选择允许运行。本包是 Windows 解压版，不需要安装。

## 打开后看不到首页

在左侧文件列表中打开：

`00_开始这里/首页.md`

## AI 沉淀助手没有反应

先确认已经运行过：

`0_配置DeepSeek_API_Key.bat`

如果刚配置完仍然没有反应，关闭降噪实验室后重新打开。

## 提示 Key 或接口错误

重新运行 `0_配置DeepSeek_API_Key.bat`，确认粘贴的是完整 DeepSeek API Key。

## 不小心改乱了系统设置

不要继续让 AI 修改系统目录。优先保留你的 `10_信息噪音` 到 `50_行动和结果` 五个沉淀目录，然后重新解压一个干净包，把沉淀目录复制进去。
