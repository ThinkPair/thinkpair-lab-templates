# API 配置说明

正常情况下，只需要回到最外层文件夹，双击：

`0_配置DeepSeek_API_Key.bat`

然后按提示输入你的 DeepSeek API Key。

## 配置完成后

配置脚本会把 Key 写入本地的 AI 助手配置文件。之后重新打开降噪实验室，就可以使用 AI 沉淀助手。

## 如果想重新配置

再次双击 `0_配置DeepSeek_API_Key.bat`，输入新的 Key 即可覆盖旧 Key。

## 安全提醒

- 本包交付时不包含真实 Key。
- 不要把配置好 Key 的整个文件夹转发给别人。
- 如果你要分享自己的笔记，请先导出需要分享的 Markdown，不要直接分享整个空间。
