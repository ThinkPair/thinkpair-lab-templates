# 噪音变化趋势

这页用来回头看：我最近被什么影响最多，哪些噪音真的转成了输入、判断或行动。

## 快速回看

```dataviewjs
const pages = dv.pages('"10_信息噪音"')
  .where(p => p.record_type === "信息噪音")
  .where(p => !p.file.name.includes("模板_"));

dv.paragraph(`当前正式噪音记录：${pages.length} 条`);

const byType = new Map();
for (const p of pages) {
  const key = p.noise_type || "未标注";
  byType.set(key, (byType.get(key) || 0) + 1);
}
dv.table(["噪音类型", "数量"], Array.from(byType.entries()).sort((a, b) => b[1] - a[1]));

const byFlow = new Map();
for (const p of pages) {
  const key = p.flow || "未流转";
  byFlow.set(key, (byFlow.get(key) || 0) + 1);
}
dv.table(["流转去向", "数量"], Array.from(byFlow.entries()).sort((a, b) => b[1] - a[1]));
```

## 最近噪音记录

```dataview
TABLE noise_type AS 类型, source AS 来源, flow AS 流转
FROM "10_信息噪音"
WHERE record_type = "信息噪音" AND !contains(file.name, "模板_")
SORT file.mtime DESC
LIMIT 20
```
