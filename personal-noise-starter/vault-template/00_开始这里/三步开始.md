# 三步开始

## 1. 配置 API Key

回到最外层文件夹，双击：

`0_配置DeepSeek_API_Key.bat`

按提示粘贴你自己的 DeepSeek API Key。输入时不会显示，完成后会提示配置成功。

## 2. 打开降噪实验室

双击：

`1_打开降噪实验室.exe`

如果提示选择文件夹，选择：

`2_个人降噪空间_首次选择这个文件夹`

## 3. 完成噪音体检

回到 [[首页]]，复制首页里的启动话术，发给 AI 沉淀助手。它会先问你几个问题，然后把第一份报告写入：

`20_我的状态和目标/我的噪音体检报告.md`

以后看到任何外界信息，都可以先丢给它，让它帮你判断应该放进哪个沉淀区。
