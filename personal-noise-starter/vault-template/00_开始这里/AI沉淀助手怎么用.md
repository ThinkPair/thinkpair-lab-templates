# AI 沉淀助手怎么用

AI 沉淀助手的核心用法不是聊天，而是写回你的个人空间。

## 可以直接这样说

```text
我刚看到一个信息，帮我判断它是噪音、输入、判断还是行动，并写到对应目录。
```

```text
这段内容让我有点焦虑。请帮我拆成：事实、对我的影响、我自己的判断、下一步行动。
```

```text
请根据我最近的噪音记录，整理 3 个反复出现的分心模式，并写入判断和复盘区。
```

```text
请把这本书/这篇文章的内容整理成我自己的输入记录，不要只做摘要，要写出它和我当前目标的关系。
```

## 它应该写到哪里

- 外界刺激、热点、短视频、课程、工具、AI 赚钱话术：`10_信息噪音`
- 书、文章、课程、资料输入：`30_输入和读书`
- 我的判断、复盘、模式识别：`40_判断和复盘`
- 下一步行动和执行结果：`50_行动和结果`
- 我的状态、目标、噪音体检：`20_我的状态和目标`

## 不要让它做什么

- 不要让它修改系统设置。
- 不要让它批量删除或移动文件。
- 不要让它替你做冲动决策。
- 不要让它把别人的观点直接变成你的计划。
