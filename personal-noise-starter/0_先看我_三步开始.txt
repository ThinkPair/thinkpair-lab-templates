降噪实验室｜个人降噪启动包 v0.1

你买到的不是一套教程，也不是一堆插件。
它的用途很简单：把每天刷到、看到、听到、买到的信息，沉淀成你自己的输入、判断、复盘和行动。

三步开始：

1. 双击「0_配置DeepSeek_API_Key.bat」
   按提示粘贴你自己的 DeepSeek API Key。输入时不会显示，这是正常的。

2. 双击「1_打开降噪实验室.exe」
   如果系统提示选择文件夹，请选择「2_个人降噪空间_首次选择这个文件夹」。

3. 打开后先看「00_开始这里/首页.md」
   首页会先让你写一句今天被什么信息打扰了。写完后，再把启动话术发给 AI 沉淀助手，它会先帮你完成「噪音体检报告」，再把后续内容写进对应沉淀区。

你只需要记住一个原则：
看到外界信息以后，不急着收藏、不急着相信、不急着买课，先写一句，再让它变成自己的记录和判断。

常见入口：
- 信息噪音：10_信息噪音
- 我的状态和目标：20_我的状态和目标
- 输入和读书：30_输入和读书
- 判断和复盘：40_判断和复盘
- 行动和结果：50_行动和结果
- API、故障排查、隐私说明：90_系统设置_不用先看

安全提醒：
- 本包不内置任何真实 API Key。
- 你的 API Key 只会写入本地配置文件。
- 不建议把整个文件夹直接发给别人，因为里面会逐渐沉淀你的个人信息。
