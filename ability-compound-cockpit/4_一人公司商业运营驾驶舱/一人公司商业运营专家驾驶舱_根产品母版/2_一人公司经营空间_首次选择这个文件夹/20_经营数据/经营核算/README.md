# 经营核算数据

这里保存“创业算账”工具经用户页内确认后生成的本地 Markdown。

- `实际核算`：已经发生的周期经营事实。快速版首层使用 8 个核心数字；完成数量为可选项，用于追加单位贡献和保本数量。
- `创业预估`：快速版首层使用单位售价、单位直接成本、固定成本、老板工资、基准完成量和最大稳定交付能力 6 个核心数字；启动现金与一次性投入为可选项。保守、基准和乐观三档由系统自动生成，永远不计入真实经营业绩。
- `产品收费方案`：每次核算使用的产品名称、收费单位和基础交付标识；完整输入仍以对应核算快照为准，复杂模型不再要求用户在前台逐项配置。
- `AI结论`：AI 对某份核算的文字解释，只在 `calculation_id + input_hash` 与最新核算完全一致时参与首页。

首页只读取最新一份 `calculation_status: confirmed` 的核算。公式数字由只读确定性引擎产生，AI 不得编辑核算记录。

快速核算按利润、现金、交付安全、单位经济、保本和产能分别记录数据就绪状态；某一项数据不足时只隐藏该项，不把其他已有依据的结论一起清空。旧版详细核算继续保留原始 `calculation_id`、`input_hash` 和结果，以只读历史快照打开，不会被快速版覆盖或自动迁移。
