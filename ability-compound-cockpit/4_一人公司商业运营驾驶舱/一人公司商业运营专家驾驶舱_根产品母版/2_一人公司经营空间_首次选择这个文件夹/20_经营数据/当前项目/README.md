# 当前项目目录

本目录只保存已经通过真实项目事实门的项目，并坚持“一项目一文件”。

项目成立必须同时满足：

1. 有明确的个人或组织对象。
2. 对方已经回复，双方开始讨论具体工作。
3. 能用一句话说清具体工作对象。

未回复对象、冷名单、泛泛交流、能力设想和 AI 推测不能放在这里；请先记录到 `40_能力商品化/验证记录`。

新项目从 `../模板_项目记录.md` 复制。用户侧核心字段只能是客户、项目、报价、回款、下一步、本周复盘。模板和本说明不代表真实项目，不参与首页统计。

归档或重开通过项目文件的隐藏字段 `record_status` 完成，AI 不移动、不删除项目文件。
