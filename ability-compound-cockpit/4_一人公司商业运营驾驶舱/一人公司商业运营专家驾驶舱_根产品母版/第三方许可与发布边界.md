# 第三方许可与发布边界

## 当前查看版

- 不包含 Obsidian 官方可执行文件。
- 不包含 Claude Code 可执行文件或运行依赖。
- 启动入口只调用用户电脑上已经安装的官方 Obsidian。
- 通过脱敏构建脚本生成的交付净包不包含任何 API Key、访问令牌、用户经营数据或 AI 会话。
- 用户完成模型配置后，本机运行副本会保存其自备凭证；该副本不再等同于可分发净包，禁止直接压缩、复制或上传。

## 随 vault 提供的社区插件

本查看版固定使用 Dataview、Homepage 和 Claudian/RealClaudian，具体版本、来源、许可证与校验值见 `LICENSES/插件来源.md`。Claudian 的交付副本做了产品化修改：显示名与默认身份改为“商业运营专家”，并禁用绕过写回预览的内联编辑入口；原作者、版本和 MIT 许可继续保留。正式公开前必须保留这些声明，不得把修改版误称为上游原版。

## 正式发布门

在取得明确的第三方再分发许可之前，不把 Obsidian、Claude Code 等闭源二进制装入 199 元收费 ZIP。商业使用许可不自动等于再次分发许可。

正式交付物不得直接从本机运行副本压缩。本机副本可能同时含用户自备模型凭证、设备/主机痕迹、Claudian 会话、RealClaudian 已打开会话标签，以及真实项目、周复盘、能力验证和确认写回记录；这些内容都属于运行副本，不属于产品母版。

发布时必须调用 `_tools/build-sanitized-release.ps1`。脚本只在工作区 `.codex_tmp` 的临时副本内执行以下动作：

- 把模型凭证替换为占位符，清空 `.claudian` 会话和运行文件。
- 只保留当前项目、归档项目、历史周复盘和能力验证目录中的 `README.md`，删除其余用户生成记录；目录外的项目、复盘和验证模板继续保留。同时删除运行副本中的 Obsidian 回收站和产品根目录经营备份，避免已删除或已备份记录重新混入发布包。
- 把 `经营状态.md`、`已确认写回记录.md` 和写回预览恢复为全新空白状态。
- 把 RealClaudian 的 `openTabs`、`activeTabId`、`tabId`、`conversationId` 等会话标签元数据恢复为空。
- 执行 `validate-package.ps1 -ReleaseMode`，再生成全文件哈希清单和单顶层 ZIP 并复核。

发布模式会拒绝任何残留的用户数据文件、非默认经营状态、非空写回日志或预览、Claudian 会话文件、RealClaudian 会话元数据和真实密钥。脚本完成或失败后均清理临时 staging，不读取到屏幕、不改写也不删除本机运行副本中的真实密钥和经营数据。
