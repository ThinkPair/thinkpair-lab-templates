# 受控交换箱

这里是“个人能力复利驾驶舱”和“一人公司商业运营专家驾驶舱”之间唯一允许使用的交换位置。两个 Obsidian 空间保持独立，不监听、不自动同步，也不直接改写对方的数据。

套件内，个人能力空间位于根目录 `2_个人能力复利空间_首次选择这个文件夹`；商业空间位于 `4_一人公司商业运营驾驶舱` 的嵌套产品包中。本交换箱位于两者之外，任何一边都没有后台监听权限。

## 两个方向

- `capability_to_business`：只接收已经由用户确认的 `capability_transfer`。
- `market_feedback_to_personal`：只接收已经脱敏并确认导出的 `market_feedback`；个人空间导入后仍保持 `draft`。

导出只复制，导入只向目标空间新建文件。工具不会移动、删除或覆盖已有卡片；重复 ID、哈希不一致、旧 schema、缺字段和来源不匹配都会停止。

## 能力去商业工具

1. 在个人能力空间用 `/ability-transfer` 自动整理能力移交草稿；正式生成和导出时确认一次摘要卡。
2. 导出卡进入 `capability_to_business`。
3. 商业工具校验类型、schema、transfer_id 和 SHA-256 后，只建立 `planned` 的 `monetization_validation`。
4. `fact_gate_confirmed` 固定为 `false`；客户、项目、报价、价格、收入和回款仍全部未发生。

## 市场反馈回个人工具

1. 商业工具只输出脱敏反馈、暴露的技能差距和下一练习候选。
2. 卡进入 `market_feedback_to_personal`，导入个人空间后仍是 `draft`。
3. 用户确认后它才能进入正式复盘输入；不会直接改写六维等级。

重复、篡改、旧 schema、字段缺失、来源卡不匹配、手机号、邮箱、金额或绝对路径会被拒绝。

## 发布边界

根产品母版和发布净包中，这两个方向目录只能保留各自的 README。测试卡位于 `_tools/fixtures/exchange`，不得复制到交换箱或正式数据目录。
