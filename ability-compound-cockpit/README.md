## Windows 双驾驶舱套件

发布净包同时包含两个彼此独立的 Obsidian 空间：

- `2_个人能力复利空间_首次选择这个文件夹`：能力怎么练、证据怎么留、下一版如何升级。
- `4_一人公司商业运营驾驶舱/一人公司商业运营专家驾驶舱_根产品母版/2_一人公司经营空间_首次选择这个文件夹`：客户、项目、报价、回款、核算与经营复盘。
- `3_受控交换箱`：两边唯一的数据桥；不监听、不自动同步、不覆盖原卡。

客户解压后的文件夹就是自己的空白使用副本，不需要把两个空间合并，也不要把套件最外层文件夹直接当作 Obsidian 仓库。

## 第一次使用

1. 安装官方 Obsidian。
2. 双击 `1_打开个人能力复利驾驶舱.cmd`。首次只选择 `2_个人能力复利空间_首次选择这个文件夹`。
3. Obsidian 会对内置插件显示一次信任提示。先核对发布包 SHA-256；确认来源可信后，由用户本人点击“信任仓库作者并启用插件”。程序不会代替用户作这个安全决定。
4. 首页和右侧“能力教练”出现后，在侧栏输入 `/skill-start`。
5. 经营工具使用 `2_打开一人公司商业运营驾驶舱.cmd` 单独打开。

没有 AI 时仍可查看首页和历史，并从首页建立“不计统计”的现场草稿；不能自动升级能力状态或生成正式移交卡。

## 两套工具的边界

- **个人能力复利驾驶舱**：练什么、证据是什么、哪里变强、下一次如何练。
- **一人公司商业运营专家驾驶舱**：客户、项目、报价、回款、利润、现金、交付和经营复盘。
- 两边只通过受控 Markdown 交换卡传递经用户确认的能力候选与脱敏市场反馈，不自动跨空间写入。

## v0.1 核心体验

1. AI 能力教练主持首次建档，生成一个主技能和六个可编辑维度。
2. 用户可在首页打开“编辑六维模板”，修改名称、顺序和证据标准。
3. 六边形只展示正式证据状态；编辑器不能修改证据等级。
4. 首页只给一个本周练习、最近作品证据、外部反馈、下一次调整和移交准备度。
5. 正式记录一条一个 Markdown；滚动草稿与 demo 不参与统计。
6. 能力移交只生成待验证商业假设，不生成客户、项目、报价或收入。

## v0.1.1 主动协作写回

- 用户调用命令或明确要求记录，即授权本轮普通能力数据写回；信息够用后 AI 直接执行、复读并汇报。
- 只有替换主技能、能力状态/版本变化、证据失效、隐私放开、批量归档和正式出库需要一次摘要确认。
- 写回由确定性批次引擎统一校验、哈希绑定和异常回滚；无证据升级、非法交换、任意 Shell 和系统目录写入继续硬拦截。

## 测试版与母版怎么同步

- 永久母版始终空白，只保存所有客户都通用的结构、界面、守卫、提示词、命令、样式和脚本。
- 测试副本用于连续找问题；用户一旦开始录入，主技能、六维、练习、证据、反馈、复盘、交换记录、AI 会话和凭证都必须保留，不能在验收后顺手清空。
- 通用问题必须同时落到两处：母版升级为新的唯一产品源，测试副本只接收同一组通用文件用于复验。
- 同步只能按显式文件清单执行，先备份测试版目标文件；不得整目录覆盖，也不得把测试数据反向复制进母版。
- 只有用户明确说“重置测试版”时，才允许把测试副本恢复为空白。
