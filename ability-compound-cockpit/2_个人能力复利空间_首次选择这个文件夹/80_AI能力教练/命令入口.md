# 七个命令入口

| 命令 | 直接完成的普通工作 | 需要另行确认的高影响变化 |
|---|---|---|
| `/skill-start` | 空白空间建立当前主技能与固定六维 | 替换已有 active 主技能 |
| `/practice-plan` | 创建针对最弱证据维度的唯一练习 | 无；若已有当前练习，先问清处理选择 |
| `/practice-close` | 关闭练习，记录结果与下一调整 | 无；本命令不升级能力 |
| `/evidence-add` | 添加一项可追溯证据 | 使旧证据失效、降低隐私保护 |
| `/skill-review` | 保存复盘、最大差距与下一练习 | 改变证据状态、能力版本或使旧结论失效 |
| `/ability-transfer` | 整理能力移交草稿 | 生成正式卡或导出交换箱 |
| `/feedback-return` | 校验并导入脱敏市场反馈草稿 | 纳入正式复盘；不直接改等级 |

所有命令共同遵循 [[80_AI能力教练/对话与确认协议]]。能力状态共同遵循 [[80_AI能力教练/证据状态判定]]。用户调用命令本身就是普通写回授权，不再追加“是否保存”。
