# 双工具交换

本目录只保存个人能力工具中的能力移交卡和市场反馈回流记录。交换通过 vault 外部的 `3_受控交换箱` 显式完成，不进行后台监听或自动跨空间写入。

## 能力移交

只有用户确认、证据不为空、适用边界明确的能力卡才可以导出。商业驾驶舱接收后只形成待验证方案，不代表已有客户、项目、报价、回款或市场需求。

## 市场反馈回流

商业驾驶舱只能返回脱敏反馈、暴露出的技能差距和一个下一练习候选。导入记录首先为 `draft`；用户确认后才改为 `confirmed`，且确认本身不自动升级维度状态、能力版本或生成练习。

模板不参与首页统计；正式记录分别保存到 `能力移交卡` 和 `市场反馈`。
