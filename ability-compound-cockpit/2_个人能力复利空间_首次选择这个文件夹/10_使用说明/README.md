# 个人能力复利驾驶舱｜使用说明

这套空间帮助你把一项主技能持续练深，并留下可以复查、复用和移交的能力证据。它不替你认证职业等级，也不保证技能提升或变现结果。

## 一条完整闭环

`能力目标 → 刻意练习 → 作品证据 → 外部反馈 → 能力版本 → 能力移交卡 → 商业验证 → 市场反馈回流`

个人能力空间只负责“能力怎么练、证据怎么留、下一版怎么升级”。客户、项目、报价、回款、成本与经营复盘继续留在商业运营空间。

## 第一次使用

1. 首次打开时，Obsidian 会询问是否信任仓库作者并启用内置插件。核对发布包来源和 SHA-256 后，由你本人确认；软件不会替你自动降低安全限制。
2. 在 AI 侧栏输入 `/skill-start`。
3. 能力教练会用每轮 1–3 个问题，和你确认一项主技能、目标成果、六个能力维度、每个维度的证据标准与当前基线。
4. 信息足够后，教练会直接建立主技能和六维、复读结果并说明写入了什么；首次建档不再重复询问“是否保存”。
5. 只有能力等级、能力版本、隐私放开、替换主技能或正式出库等高影响变化，才会展示一张简短确认卡。
6. 回到首页，只执行本周唯一刻意练习。

## 日常入口

| 你要做什么 | 输入 |
|---|---|
| 建立或重建主技能 | `/skill-start` |
| 生成本周唯一练习 | `/practice-plan` |
| 关闭一次练习并提炼调整 | `/practice-close` |
| 添加作品、对比、评价或证书 | `/evidence-add` |
| 做周期能力复盘 | `/skill-review` |
| 准备向商业工具移交能力候选 | `/ability-transfer` |
| 接收商业验证返回的脱敏反馈 | `/feedback-return` |

## 六维模板可以改什么

你可以在专用六维编辑器里修改六个维度的名称、顺序和证据标准，并在同一页预览后一次确认保存。六个槽位数量固定，证据状态不能在编辑器中手动修改。

## 什么会进入统计

只有 `record_status: confirmed` 的正式记录进入首页与复盘统计。`draft`、`demo`、空模板和历史归档不计入。
