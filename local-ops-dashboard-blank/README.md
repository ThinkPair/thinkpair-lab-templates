# Local Ops Dashboard Blank Pack（本地经营看板空白包）

Blank local web dashboard for multi-platform ops funnel visualization.

Public tree uses **demo/synthetic data only**. Real operator archives and restore scripts were removed.

## Run

Open `打开经营看板.cmd` on Windows, or serve `app/` with the scripts under `runtime/`.

Edit `app/data/current-data.js` (schema documented in `01_看板数据.md`).
